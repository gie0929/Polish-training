Polski A1 — Firebase Word Seeder

📤 Upload words to Firestore

This page holds the original A1 vocabulary and sentence lists and uploads them once into your Firestore database, so the main app can load them from there instead of a hardcoded list.

⚠️ Not connected to Firebase. Fill in the firebaseConfig object near the top of the script in this file, then reload the page.

1. Set up your Firebase config

Open this file and fill in the firebaseConfig object with your project's values (from Firebase Console → Project settings → General → Your apps). This is the same config you'll paste into index.html.

Make sure Firestore is enabled for the project, and that its security rules allow writes (at least temporarily) for this one-time upload.
